## 头像坐标

`TableLayoutProfile` 保存设计空间的头像尺寸、本人牌尺寸/间距、本人信息/庄家/操作区偏移及对手庄家偏移。`TableLayout` 按现有 viewport unit 与 seat scale 转换为局部单位。短屏先调整本人头像锚点，其他元素随头像移动。CSS 中的 px 是组件局部坐标，不是固定设备像素；不将 px 机械替换为 rem。

均衡基准 440×782：头像 60，手牌 40×56，手牌中心向下 65，净距 7；本人庄家（−54，118）。经典手牌 50×71，庄家（−107，−7）。竞技椭圆保留 50 头像，同一手牌偏移产生 12 的净距。新布局操作区及拉杆跟随本人头像，确认按钮与加注按钮重合。初代保留原布局。

均衡原稿从 Figma 原生导出，节点 `12026:53752`。椭圆和经典保留用户最终交付的完整 PNG，同时提供明确坐标裁切。初代已按用户提供的位置补取完整原稿 `748:23506`（1242×2688，2x 导出）。初代与新布局比例不同，报告保持原比例。

## 离线工作台

启动 MX 后打开 `/tests/fixtures/layout-audit.html`。默认均衡八人桌，可切四布局、2–9 人、本人/作用座位、庄家、2/4/5/6 张手牌、尺寸、语言和滑杆模式。

85 个场景及每项元素、操作步骤见报告的 `offline-scenarios.json`。包括本人/他人庄家、等待/补盲/留座各原因、托管、倒计时、弃牌选亮牌、十种赢家牌型、多池、带入/站起、完整一手单步和自动播放、重连/切桌/离桌、保险/二道牌/鱿鱼/蘑菇/暴击/Jackpot/CallTime、聊天/牌谱/战绩/资料/设置、音视频占位和赛事状态。

逐元素编辑器可改变指定座位的名称、头像、操作文字、筹码、下注、性别值、胜率、等待/留座/保险状态、蘑菇/鱿鱼、弃牌、托管、本轮已行动、牌值、选亮牌、高亮、上浮和赢家信息；按钮可换庄家和行动座位。修改发生在隔离 AuditHost，不向真实服务器发消息。特殊玩法 DemoFeatures 已改为读取 mySeat，不再固定座位 1。

音视频是 DOM 占位，不申请硬件或加入 RTC。支付订单、外壳客服和安全卫士等外部流程不冒充完成。截图只是场景证据，不能代替真实服务器验收或逐像素通过。

## 可重复验证

- `npm run check`，`npx tsc -p tests/fixtures/tsconfig.json`。
- `npx tsc -p tsconfig.test.json` 后运行测试；全量 227 项通过，新增非第 1 座玩法测试另行通过。
- `npm run build` 通过，保留既有大 chunk 警告。
- `verify-avatar-audit.mjs`：四布局 × 五视口，检查出界、本人庄家与手牌/筹码相交、确认按钮位置；另四布局实际执行选牌/取消/结算/清桌以及一手八步，共 28 条通过。
- `capture-audit-scenarios.mjs`：逐布局逐场景截图及页面错误记录，不把截图成功标成完整验收通过。
- `verify-workbench.mjs`：多池购买、二道牌、牌谱详情、带入与逐元素编辑器交互。
- `build-figma-audit-report.mjs`：生成含原图、逐场景截图、清单与 CSV 的本地报告。

浏览器脚本使用用户授权的 Playwright，通过 `MX_PLAYWRIGHT_MODULE` 指向已安装的 playwright-core。产物没有账号、密码或 token。
